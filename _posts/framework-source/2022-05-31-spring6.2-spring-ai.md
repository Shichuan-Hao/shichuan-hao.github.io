# Spring6.2新特性与SpringAI实战

## 一、Spring6.2：异步并行Bean创建

Spring6.2 支持 IOC 容器中 Bean 的**异步并行创建**，可显著减少启动时间。

### 使用方式

```java
// 标记要异步创建的Bean
@Bean(bootstrap = Bean.Bootstrap.BACKGROUND)
public AService aService() { ... }

// 配置线程池
@Bean
public Executor bootstrapExecutor() {
    return Executors.newCachedThreadPool();
}
```

### 也可通过 BeanDefinition 批量设置

```java
@Component
public class BatchBeanDefinitionRegister implements BeanDefinitionRegistryPostProcessor {
    @Override
    public void postProcessBeanDefinitionRegistry(BeanDefinitionRegistry registry) {
        for (int i = 0; i < 10; i++) {
            RootBeanDefinition bd = new RootBeanDefinition(AService.class);
            bd.setBackgroundInit(true);  // 异步创建
            registry.registerBeanDefinition("AService" + i, bd);
        }
    }
}
```

### 几个关键问题

**Q1：异步Bean创建中，另一个线程getBean会怎样？**

会等待异步线程完成：异步创建时往三级缓存放入 `future.join()`，其他线程获取时回调等待。

**Q2：同一个Bean懒加载一起创建会怎样？**

不会阻塞——标记正在创建时，若已有线程在创建则直接抛 `BeanCurrentlyInCreationException`。这是从悲观锁（互斥等待）改为乐观锁（快速失败）。

**Q3：两个异步lazy Bean循环依赖，会死锁吗？**

不会。Bean实例化后会覆盖三级缓存，阻止互相join。

## 二、Spring6.2：defaultCandidate 属性

```java
@Bean(defaultCandidate = false)
public UserService userService() { ... }
```

`defaultCandidate=false` → 该Bean不会被 `@Autowired` 自动注入（需通过 `@Qualifier` 明确指定）。

## 三、SpringAI 实战

SpringAI 是 Spring 官方推出的 AI 集成框架，可以方便地对接 ChatGPT 等大模型。

### Maven 依赖

```xml
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.springframework.ai</groupId>
            <artifactId>spring-ai-bom</artifactId>
            <version>1.0.0-SNAPSHOT</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-openai-spring-boot-starter</artifactId>
</dependency>
```

### 配置

```yaml
spring:
  ai:
    openai:
      api-key: ${OPEN_AI_KEY}
      base-url: ${OPEN_AI_URL}
```

### 对话（Chat Client）

```java
@GetMapping("/ai/simple")
public Map<String, String> completion(@RequestParam(defaultValue = "给我讲个笑话") String message) {
    var value = chatClient.prompt()
        .user(message)
        .call()
        .content();
    return Map.of("generation", value);
}
```

### 流式对话（SSE）

```java
@GetMapping(value = "/ai/stream", produces = "text/sse;charset=UTF-8")
public Flux<String> stream(@RequestParam(defaultValue = "给我讲个笑话") String message) {
    return chatClient.prompt()
        .user(message)
        .stream()
        .content();
}
```

### 文生图（DALL-E）

```java
@GetMapping("/ai/img")
public String image(@RequestParam(defaultValue = "猫") String message) {
    ImageResponse response = imageClient.call(
        new ImagePrompt(message, OpenAiImageOptions.builder()
            .withQuality("hd")
            .withN(1)
            .withModel(OpenAiImageApi.ImageModel.DALL_E_2.getValue())
            .withHeight(256)
            .withWidth(256).build()));

    String url = response.getResult().getOutput().getUrl();
    return "<img src='" + url + "'/>";
}
```

### 语音转文字（Audio → Text）

```java
@GetMapping("/ai/audit2text")
public String audit2text() {
    var audioFile = new ClassPathResource("/hello.mp3");
    AudioTranscriptionPrompt transcriptionRequest = 
        new AudioTranscriptionPrompt(audioFile, transcriptionOptions);
    AudioTranscriptionResponse response = audioClient.call(transcriptionRequest);
    return response.getResult().getOutput();
}
```

### 文字转语音（Text → Audio）

```java
@GetMapping("/ai/text2audit")
public String text2audit() {
    ResponseEntity<byte[]> speech = openAiAudioApi.createSpeech(
        OpenAiAudioApi.SpeechRequest.builder()
            .withVoice(OpenAiAudioApi.SpeechRequest.Voice.ONYX)
            .withInput("你好，我是徐庶").build());
    byte[] body = speech.getBody();
    writeByteArrayToMp3(body, System.getProperty("user.dir"));
    return "ok";
}
```

### 多模态（图片理解）

```java
@GetMapping("/ai/mutil")
public String mutilModel() throws IOException {
    byte[] imageData = new ClassPathResource("/test.png").getContentAsByteArray();
    var userMessage = new UserMessage(
        "这个图片你看出什么?",
        List.of(new Media(MimeTypeUtils.IMAGE_PNG, imageData)));

    ChatResponse response = chatClient.call(new Prompt(userMessage,
        OpenAiChatOptions.builder()
            .withModel(OpenAiApi.ChatModel.GPT_4_TURBO_PREVIEW.getValue())
            .build()));

    return response.getResult().getOutput().getContent();
}
```

## 四、Function Call（函数调用）

AI 本身不具备实时信息能力，需要通过接口帮助 AI 完成。

### 流程

```
用户问："现在长沙天气是什么？"
    │
    ▼
ChatGPT 识别需要function-call
    │
    ▼
返回 function-call 请求（函数名+参数）
    │
    ▼
Spring 调用对应Bean的apply方法 → 查天气
    │
    ▼
结果再次发给ChatGPT → 组织语言 → 返回最终答案
```

### 代码实现

```java
// 1. 发送时设置 Function
ChatResponse response = chatClient.call(new Prompt(
    List.of(userMessage),
    OpenAiChatOptions.builder()
        .withFunction("getWaitTime")
        .build()));

// 2. 注册 Function Bean
@Bean
public Function<WaitTimeService.Request, WaitTimeService.Response> getWaitTime() {
    return new WaitTimeService();
}

// 3. 实现 Function 逻辑
public class WaitTimeService implements Function<Request, Response> {
    @Override
    public Response apply(Request request) {
        String name = request.name();
        String location = request.location();
        // 查数据库/API获取天气...
        return new Response(location + "有10个！");
    }

    public record Request(String name, String location) {}
    public record Response(String weather) {}
}
```

### Function Call 源码流程

```
1. createRequest(prompt) → 将 @Description、属性、函数名封装为 tools
2. doChatCompletion(request) → 请求OpenAI API（带tools）
3. handleFunctionCallOrReturn() → 执行 function callback
   ├── 解析 arguments JSON
   ├── 调用 Function.apply()
   └── 返回数据再次请求大模型
```

## 五、总结

```
Spring6.2：
├── 异步Bean创建 → 大幅减少启动时间（并行createBean）
├── 乐观锁替代悲观锁 → 更快失败
└── defaultCandidate → 精细控制依赖注入

SpringAI：
├── ChatClient → 对话/流式对话
├── ImageModel → DALL-E 文生图
├── AudioModel → 语音转文字 / 文字转语音
├── 多模态 → 图片理解（GPT-4V）
└── Function Call → 让AI调用你的函数
```
